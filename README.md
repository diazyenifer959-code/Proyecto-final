🎲 Torneo de Dados

Descripción

Este proyecto consiste en desarrollar una aplicación de consola en C++ que simula un torneo de dados entre jugadores. Permite registrar participantes, realizar rondas, lanzar dados, calcular puntuaciones y determinar al ganador del torneo.

Objetivo

Practicar los fundamentos de programación en C++, utilizando funciones, estructuras, vectores, ciclos, condicionales y validaciones.

Funcionalidades

Registro de jugadores.

Lanzamiento de dados.

Desarrollo de rondas.

Cálculo de puntuaciones.

Visualización de resultados.

Determinación del ganador.

Validación de entradas.

Tecnologías utilizadas

C++

Visual Studio / compilador C++

Git

GitHub
